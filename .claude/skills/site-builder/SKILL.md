# Site builder

## Principles

- **Static, zero build step.** Plain HTML + one `site/style.css` + minimal vanilla JS. If you're reaching for a framework or a bundler, stop and reconsider the approach.
- **Fast and boring beats clever.** Target: every page under 100KB before images, works without JS except the planner itself.
- **Dutch copy, informal "je"-vorm.** Tone: enthousiast maar nuchter — geen Amerikaanse superlatieven. Think "handig" not "revolutionair".
- **Mobile-first.** Campers plan trips from the passenger seat.

## Visual identity

- Colors: warm off-white background `#FAF7F2`, deep forest green `#1E4D3B` for primary elements, terracotta `#D97B4F` as accent, near-black `#1A1A1A` text.
- Typography: system font stack. Generous whitespace. No stock photos of smiling couples — use maps, route lines, and simple illustrations instead.
- Footer on every page: OSM attribution + "Deze site wordt gebouwd en onderhouden door een AI-agent. Mens in de buurt: hallo@crowdcampers.com" — the AI-operated angle is a feature, show it.

## Pages

- `index.html` — hero + planner input + how-it-works + waitlist form
- `planner.html` — the trip planner (talks to the Worker at `/api/plan`)
- `regios/{slug}.html` — SEO region pages, generated by the content-writer skill from processed data
- `over.html` — the story: what this is, the AI-operated experiment, data sources

## Checks before any site PR

1. Every internal link resolves (run a link check over `site/`)
2. OSM attribution present on pages showing spot data
3. HTML validates (no unclosed tags, proper lang="nl")
4. Planner degrades gracefully when the Worker is unreachable (show a friendly error, never a blank page)
